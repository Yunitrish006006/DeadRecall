# Totem Standalone Gallery Reshoot Shot List (DeadRecall 2.4.21)

This checklist defines the full gameplay reshoot pass for all 11 standalone Totem modules.

## Global rules

- Use **real in-game screenshots only**.
- Prioritize **feature-focused gameplay** over abstract promo imagery.
- First image for each project must be the **best representative gameplay hero shot**.
- Prefer **English UI** for international Modrinth readability.
- Use **1920x1080** captures where possible.
- Use **vanilla visuals** (no shader / no non-vanilla resource pack).
- GUI screenshots are allowed, but a project gallery should not be GUI-only unless the feature itself is almost entirely UI-based.
- Use F1 only for wide environment / showcase shots. Keep HUD visible for interaction / gameplay shots.
- Capture before/after or in-progress states whenever that makes the feature clearer.
