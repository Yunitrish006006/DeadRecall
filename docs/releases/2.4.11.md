# DeadRecall 2.4.11

DeadRecall 2.4.11 adds guided module onboarding, interactive carried-backpack
inventory access, automatic death-time soulbound interface selection, and the
new Totem Locksmith fixed-storage protection module.

## Exact Versions

- TotemCore `0.6.0`
- TotemRemnant `0.2.11`
- TotemDiscordBridge `0.1.6`
- TotemAutomata `0.1.12`
- TotemAlchemy `0.1.23`
- TotemEnchanting `0.1.5`
- TotemExcavation `0.1.2`
- TotemLocksmith `0.1.0`
- TotemVanillaTweaks `0.1.8`
- TotemNexus `0.2.6`
- TotemVillagers `0.1.23`

## Guided Manuals

- A basic guide is granted once on first world entry and explains how to obtain
  installed module chapters.
- Each participating module now starts with crafting its source block, followed
  by using a Book or Totem Manual on that block to acquire the method chapter.
- Later advancement branches depend on chapter acquisition. Module branch roots
  no longer grant themselves simply because the player joined.

## Backpack Access

- The carried-backpack side panel in the normal player inventory now accepts
  standard take, place, swap, number-key, throw, drag, double-click, and
  shift-click operations.
- All mutations continue through the normal server-authoritative menu protocol.

## Soulbound Scan

- On death, Remnant scans the main hand, offhand, hotbar, then remaining
  inventory for one resolver-valid Nexus teleport interface.
- The selected item no longer needs to have completed a previous teleport.
- Normal travel cost, access, and safe-landing checks still apply after respawn.

## Storage Locks

- One Padlock protects a supported fixed-Hopper-connected container network.
- The first locked container is the persistent root. If a middle connector is
  broken, only the component containing that original root remains locked.
- The Padlock stays assigned until the final logical root-side container is
  removed and can drop at most once.
- Non-owners may still break containers through normal Minecraft rules. A
  successful break publishes one event that TotemDiscordBridge can deliver.
- Server-owned ACLs, physical keys, automation policies, placement checks,
  explosions, pistons, and persistence are enforced without a global tick scan.

## Validation

- Totem Locksmith passed unit, performance, 12/12 required Fabric GameTests,
  and a two-JVM seed/reload persistence probe.
- TotemCore and every exact-version standalone module were rebuilt on Java 25.
- The release bundle is validated against all eleven nested module IDs,
  versions, SHA-512 hashes, resources, and compatibility boundaries.
