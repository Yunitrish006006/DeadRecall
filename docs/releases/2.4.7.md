# DeadRecall 2.4.7 變更清單

## 相容主機與舊物品 ID

- DeadRecall 外層 JAR 現在只保留舊 `deadrecall:*` 物品 ID 的解碼與
  component-preserving 遷移，以及固定 Totem 模組圖的 nested JAR 載入。
- 背包、煉金、銅扳手、Nexus 與 Discord 等功能實作由各自的 Totem 模組
  擁有；不要把獨立功能 JAR 與整合 JAR 同時放入 `mods/`。

## 精確多人連線版本

- Client 與 Server 在登入前會比對 DeadRecall 與全部八個 Totem 模組的
  精確版本；任何一個版本不同都會被拒絕進入世界。

## 精確模組組合

- TotemCore `0.4.0`
- TotemRemnant `0.1.7`
- TotemDiscordBridge `0.1.4`
- TotemAutomata `0.1.9`
- TotemAlchemy `0.1.7`
- TotemEnchanting `0.1.3`
- TotemVanillaTweaks `0.1.5`
- TotemNexus `0.2.2`

## 驗證

- Thin-host JAR 只包含相容遷移類別與固定 nested JAR 圖。
- 新版八模組 JAR 的 SHA-512 已鎖定在 release manifest，並完成本機組裝
  建置驗證。
