# DeadRecall 2.4.6 變更清單

## 靈魂綁定傳送介面

- 移除免費且繞過 Nexus 規則的 `/back` 與舊死亡座標管理。
- 每次成功完成 Nexus 傳送後，實際使用的介面物品會取得新的玩家專屬
  token；只有最後一次成功使用的那一個物品有效。
- 玩家死亡時 Remnant 會從物品欄保留有效物品的一個，其餘堆疊仍照常進入
  死亡背包；重生或再次登入後才安全還原。
- 取消、失敗傳送與單純開啟地圖不會換發 token；帶有消失詛咒的物品也不會
  被保留。

## Discord Bridge 翻譯與模組接線

- 成就通知會依 advancement ID 回退，不再把未見過的進度顯示為未知成就。
- Server 會讀取所有已安裝模組的 `en_us`／`zh_tw` 語言資源，其他模組的
  advancement 翻譯不再需要手動維護對照表。
- 原版繁體中文會由 Mojang 官方資源索引下載、驗證與快取；下載失敗時仍使用
  內建英文與既有快取安全退回。
- Remnant、Nexus 與 Discord Bridge 改以 TotemCore 型別事件接線，整合包
  不再保留功能專屬的反射 bridge。

## 精確模組組合

- TotemCore `0.3.0`
- TotemRemnant `0.1.6`
- TotemDiscordBridge `0.1.3`
- TotemAutomata `0.1.8`
- TotemAlchemy `0.1.6`
- TotemEnchanting `0.1.2`
- TotemVanillaTweaks `0.1.4`
- TotemNexus `0.2.1`

玩家只需安裝 `deadrecall-2.4.6.jar` 與 Fabric API；不要把上述獨立 JAR
同時放入 `mods/`。

## 驗證

- Core 單元測試、八個功能模組 production build 與必要 Fabric GameTests。
- Remnant 靈魂綁定資料的兩 JVM restart persistence。
- SHA-512 lockstep assembly、跨模組 dependency boundary 與資源檢查。
- 精確九模組圖 Dedicated Server 啟動至 `Done`，且單一 nested-JAR
  整合包已確認由 Fabric 展開並載入全部八個固定版本。
