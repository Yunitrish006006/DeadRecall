# DeadRecall 2.4.5 變更清單

## 背包染色

- 四級一般背包都能使用任意原版染料染色，並沿用原版皮革物品的混色規則。
- 染色與洗色會保留背包內容、自訂名稱及其他 Data Components。
- 使用裝水煉藥鍋可洗回原本棕色；死亡背包維持不可染色。

## 物品 ID 相容遷移

- Remnant 五個背包的新物品 ID 改為 `totem:remnant/*`。
- Automata 銅扳手的新物品 ID 改為 `totem:automata/copper_wrench`。
- Alchemy 八個物品的新物品 ID 改為 `totem:alchemy/*`。
- 原有 `deadrecall:*` ID 繼續註冊；使用、合成或煉藥鍋轉換時會保留
  Components，逐步換成 canonical ID，不會掃描離線玩家或未載入區塊。

## 精確模組組合

- TotemCore `0.2.0`
- TotemRemnant `0.1.5`
- TotemDiscordBridge `0.1.2`
- TotemAutomata `0.1.7`
- TotemAlchemy `0.1.5`
- TotemEnchanting `0.1.1`
- TotemVanillaTweaks `0.1.3`
- TotemNexus `0.2.0`

玩家只需安裝 `deadrecall-2.4.5.jar` 與 Fabric API；不要把上述獨立 JAR
同時放入 `mods/`。

## 驗證

- Remnant 33/33、Automata 20/20、Alchemy 11/11 required GameTests 通過。
- 三個模組的 Java 25 production build 通過。
- 八個 nested JAR 由 SHA-512 lockstep manifest 固定。
- 單一 DeadRecall 整合 JAR Dedicated Server 啟動與模組載入 smoke 通過。
