# DeadRecall 2.4.15

DeadRecall 2.4.15 restores the shared Totem manual path, fixes two-hand manual
consolidation, and updates the finite villager economy without reintroducing
gameplay into the compatibility host.

## Exact Versions

- TotemCore `0.6.0`
- TotemRemnant `0.2.11`
- TotemDiscordBridge `0.1.6`
- TotemAutomata `0.1.12`
- TotemAlchemy `0.1.23`
- TotemEnchanting `0.1.5`
- TotemExcavation `0.1.2`
- TotemLocksmith `0.1.0`
- TotemVanillaTweaks `0.1.8`
- TotemNexus `0.2.6`
- TotemVillagers `0.1.26`

## Shared Manuals

- The TotemCore manual branch is included in the default source history and in
  the bundled Core artifact.
- Using a manual source while holding one recognized guide in each hand now
  consolidates both books and the newly discovered module section into one
  manual, then consumes the second guide.
- Legacy module guides contribute only their own module section during
  migration instead of incorrectly unlocking every registered chapter.

## Villager Economy

- Trade spread corrections keep villagers profitable instead of allowing
  emerald-generating buy/sell loops.
- Bred villagers no longer receive minted starter assets. In enforced economy
  mode, both parents must each contribute four Emeralds and three Bread before
  the child receives the complete eight-Emerald, six-Bread endowment.
- Underfunded births transfer nothing and remain ineligible for a later
  world-generation starter grant.

## Bundle Safety

- The outer DeadRecall JAR remains a migration-only host with fourteen legacy
  item-ID mappings; all gameplay is supplied by the eleven nested Totem JARs.
- Bundle metadata now derives exact module dependencies from each nested JAR,
  preventing a version bump from leaving stale pins behind.

## Validation

- TotemCore `check` passed with the manual consolidation regression test.
- TotemVillagers passed 123 required Fabric GameTests and 70 JUnit tests.
- The bundle thin-host guard passed and the resulting JAR contains only 30
  outer entries, including exactly eleven nested module JARs.
- A clean Fabric Loader 0.19.3 / Minecraft 26.2 dedicated server loaded all
  modules, reached `Done (1.474s)`, and shut down normally.
