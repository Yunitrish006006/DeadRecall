# DeadRecall 2.4.8

DeadRecall 2.4.8 將目前已驗證的十個 Totem 功能模組整合為單一 Fabric
nested-JAR 發佈包，並維持外層只負責舊物品 ID 遷移與精確版本組裝。

## 精確模組版本

- TotemCore `0.5.0`
- TotemRemnant `0.2.9`
- TotemDiscordBridge `0.1.5`
- TotemAutomata `0.1.11`
- TotemAlchemy `0.1.22`
- TotemEnchanting `0.1.4`
- TotemExcavation `0.1.1`
- TotemVanillaTweaks `0.1.7`
- TotemNexus `0.2.4`
- TotemVillagers `0.1.10`

## 整合變更

- Excavation 與 Villagers 正式加入 DeadRecall 依賴與 nested-JAR 清單。
- TotemCore 的多人連線版本握手開始比對 Excavation 與 Villagers。
- Automata 僅接受目前正式的 `totem:excavation/*_hammer`；未安裝過的
  Blossom 舊鎚 ID 不納入相容與遷移範圍。
- 完整伺服器與無畫面客戶端啟動測試均成功載入十個模組。
