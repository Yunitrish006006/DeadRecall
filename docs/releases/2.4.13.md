# DeadRecall 2.4.13

DeadRecall 2.4.13 fixes Lumberjack tree discovery and removes the villager
runtime scans that could slow every loaded entity in animal-heavy worlds.

## Exact Versions

- TotemCore `0.6.0`
- TotemRemnant `0.2.11`
- TotemDiscordBridge `0.1.6`
- TotemAutomata `0.1.12`
- TotemAlchemy `0.1.23`
- TotemEnchanting `0.1.5`
- TotemExcavation `0.1.2`
- TotemLocksmith `0.1.0`
- TotemVanillaTweaks `0.1.8`
- TotemNexus `0.2.6`
- TotemVillagers `0.1.25`

## Lumberjack Work

- Tree discovery now skips middle trunk blocks and continues until it finds
  the true base, including when the worker stands above the tree base.
- Generated Lumberyard zones reserve a sixteen-block vertical trunk column so
  naturally regrown Oaks remain inside their persistent work zone.
- Bootstrap validation accepts the normal range of vanilla tree heights rather
  than requiring exactly four trunk logs.

## Entity Performance

- Loaded villagers are collected once per level and tick, then shared by the
  economy, work, food, logistics, guard, and workforce runtimes.
- Idle discovery is UUID-staggered to once per second, while active work still
  progresses every tick; navigation retries are also bounded.
- Farmers scan a field once for every supported crop instead of rescanning it
  separately for Wheat, Carrots, Potatoes, and Beetroot.
- Village logistics snapshots each worker's demand once per delivery pass
  instead of repeatedly rebuilding live trades for every buyer-supplier pair.
- Shepherd searches use a local job-site area rather than every loaded Sheep.

## Validation

- Totem Villagers passed all 121 required Fabric GameTests on Java 25.
- The complete client suite passed, including Lumberjack skin, trade catalogue,
  mine, mangrove village, natural-village, and interaction tests.
- A dedicated-server stress world with 200 active Cows and 16 active Farmers
  completed accelerated ticks at 8.08 ms/tick (about 123 TPS capacity).
- The same 200-entity extreme scan case with 64 idle Farmers improved from
  118.79 ms/tick to 6.71 ms/tick after warm-up.
