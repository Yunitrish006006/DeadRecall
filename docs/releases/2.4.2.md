## 主要變更

- TotemCore 新增向後相容的死亡背包反向綁定 lifecycle callback。
- TotemRemnant 在建立死亡背包 ItemEntity 後回報 UUID，綁定失敗時完整
  rollback 節點與實體。
- TotemNexus 將可選 `backpack_id` 寫入既有 Space Unit SavedData，提供
  重複活動背包綁定診斷，不搜尋或載入 chunk。
- 外部 Nexus authority 補上非管理員 query-payload 拒絕測試，並以三階段
  Dedicated Server probe 驗證 legacy migration 與第二次 JVM restart。
- Safe Landing 搜尋避免在 Server thread 上同步載入缺塊。
- 分拆模組的圖示、進度與資源 ownership 收斂；DeadRecall 保留必要的
  GameTest rollback fixture。
- `zh_cn` 不再維護獨立來源，建置時直接由 `zh_tw` 產生。
