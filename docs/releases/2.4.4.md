# DeadRecall 2.4.4 變更清單

狀態：開發候選。

## 單一安裝檔

DeadRecall 現在可以把下列八個已拆分模組封裝成 Fabric nested JAR：

- TotemCore `0.2.0`
- TotemRemnant `0.1.4`
- TotemDiscordBridge `0.1.2`
- TotemAutomata `0.1.6`
- TotemAlchemy `0.1.4`
- TotemEnchanting `0.1.1`
- TotemVanillaTweaks `0.1.3`
- TotemNexus `0.2.0`

玩家只需要安裝 `deadrecall-2.4.4.jar` 與 Fabric API。不可再把上述獨立
JAR 同時放入 `mods`，否則 Fabric 會偵測到重複 mod ID。

## 驗證

- DeadRecall build 與 JVM tests 通過。
- 八個 nested JAR 均與已驗證獨立 artifact 的 SHA-512 完全一致。
- 隔離 Dedicated Server 僅安裝 DeadRecall 整合 JAR 與 Fabric API，
  Fabric 正確辨識全部八個 nested modules。
- 伺服器到達 `Done`、執行 Remnant 容器掃描，並正常保存三個維度後停止。
