# DeadRecall 2.4.10

DeadRecall 2.4.10 讓一般玩家透過 `/deadrecall deathnodes` 或
`/deadrecall deathpoints` 自行刪除本人擁有的死亡傳送點。

## 精確模組版本

- TotemCore `0.5.0`
- TotemRemnant `0.2.10`
- TotemDiscordBridge `0.1.5`
- TotemAutomata `0.1.11`
- TotemAlchemy `0.1.22`
- TotemEnchanting `0.1.4`
- TotemExcavation `0.1.1`
- TotemVanillaTweaks `0.1.7`
- TotemNexus `0.2.5`
- TotemVillagers `0.1.22`

## 玩家死亡傳送點

- 一般玩家只會收到 Server 依登入 UUID 篩選的本人節點。
- 選取單一節點後需在 30 秒內再次確認；活動節點可直接刪除。
- 刪除會清理 Space Unit、discovery 與 favorite reference，但不會移動或
  刪除死亡背包。
- 外人 UUID、管理員動作、批次動作與偽造 token 都由 Server 拒絕。
- 管理員仍保留跨玩家篩選、安全傳送、停用與批次清理功能。
