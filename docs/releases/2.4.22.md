# DeadRecall 2.4.22

DeadRecall 2.4.22 is the final compatibility-transition bundle for moving an existing DeadRecall world to standalone Totem modules.

## Migration safety

- TotemCore 0.7.1 permanently owns the 14 retained `deadrecall:*` item aliases.
- Old stacks therefore remain decode-safe after the DeadRecall host is removed, including stacks hidden in offline player data or unloaded containers.
- Canonical conversion remains lazy and preserves the complete Data Component patch and item count.
- If the owning feature module is temporarily absent, the legacy placeholder remains intact instead of being discarded; it can migrate once the feature module is installed again.

## Bundle graph

This transition bundle contains 10 modules:

- TotemCore 0.7.1
- TotemRemnant 0.2.13
- TotemDiscordBridge 0.1.8
- TotemAutomata 0.1.15
- TotemAlchemy 0.1.26
- TotemEnchanting 0.1.8
- TotemExcavation 0.1.5
- TotemLocksmith 0.1.4
- TotemVanillaTweaks 0.1.10
- TotemNexus 0.3.0

**TotemVillagers is intentionally not bundled and is no longer a DeadRecall dependency.** Install it separately only when wanted.

## Recommended server transition

1. Back up the world.
2. Replace DeadRecall 2.4.21 with DeadRecall 2.4.22 and start the server successfully once.
3. Confirm the startup log reports that all 14 TotemCore-owned legacy aliases were verified.
4. Stop the server normally.
5. Remove the DeadRecall host and install the desired standalone Totem modules. Keep TotemCore 0.7.1 or newer.
6. TotemVillagers may be omitted.

The one-time 2.4.22 boot is a compatibility checkpoint, not a destructive whole-world rewrite. The important safety change is that TotemCore itself now retains the old identifiers, so unvisited legacy stacks remain readable.
