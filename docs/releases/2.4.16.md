# DeadRecall 2.4.16

DeadRecall 2.4.16 replaces the stale Villagers input used by 2.4.15 with a
distinct, traceable TotemVillagers release. The outer JAR remains a
migration-only compatibility host.

## Villager Corrections

- Packages the current Miner navigation and world-work runtime that is covered
  by the natural single-player world Client GameTest.
- Includes the village-positive trade spreads and the parent-funded newborn
  endowment that were missing from the stale Villagers JAR embedded in 2.4.15.
- Gives the corrected Villagers artifact a new version, preventing an older
  binary with the same filename from being mistaken for the reviewed build.
